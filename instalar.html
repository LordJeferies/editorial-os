MACOS · INSTALACIÓN COMPLETA

Instala Editorial OS otra vez desde cero.

Un instalador guiado vuelve a preparar la app Desktop, el acceso del Escritorio y el MCP local. La versión web/PWA sigue funcionando durante todo el proceso.

Descargar instalador completo

Desktop

Crea Editorial OS.app en ~/Applications y su acceso en el Escritorio.

MCP

Instala el servidor MCP local en ~/.editorial-os-mcp.

Backup

Antes de reemplazar la instalación local, guarda una copia de seguridad en Documentos.

Paso a paso

1

Descarga el instalador

Usa el botón de arriba o copia el comando de Terminal.

2

Escribe la clave de instalación

El instalador pedirá la clave acordada antes de continuar.

3

Desktop

Valida las herramientas de Apple, compila el wrapper WKWebView y coloca la app en Aplicaciones.

4

MCP

Descarga la versión actual del MCP, instala dependencias y te pide el usuario real de Supabase.

5

Verificación

Comprueba la app, ejecuta el self-test del MCP y deja un reporte en el Escritorio.

Comando directo

cd "$HOME/Downloads" curl -fL "https://lordjeferies.github.io/editorial-os/INSTALL_EDITORIAL_OS_COMPLETE.command" -o INSTALL_EDITORIAL_OS_COMPLETE.command chmod +x INSTALL_EDITORIAL_OS_COMPLETE.command ./INSTALL_EDITORIAL_OS_COMPLETE.command

Lo que NO borra

  • La GitHub Page pública.
  • La PWA/web del celular.
  • Los datos que ya estén guardados en Supabase.
  • El repositorio GitHub.

Si falta algo

Si macOS necesita instalar Command Line Tools, el instalador abre el flujo oficial de Apple y te indica que vuelvas a ejecutar el mismo comando cuando termine.

El MCP requiere Node.js 22+. Si tu Mac ya tiene Homebrew, el instalador MCP puede instalar o actualizar Node automáticamente.
