# QA V12.16 · instalación completa

## Instalador completo

- macOS only.
- pide clave de instalación antes de continuar.
- crea backup si encuentra Desktop o MCP previos.
- no toca GitHub Pages ni datos remotos de Supabase.
- detecta Command Line Tools.
- descarga los instaladores actuales desde GitHub Pages.
- valida ambos scripts con `bash -n`.
- instala y verifica `~/Applications/Editorial OS.app`.
- instala y verifica `~/.editorial-os-mcp/run-mcp.sh`.
- ejecuta `run-mcp.sh --self-test`.
- deja reporte y log.
- abre la app al terminar.

## Instalación desde cero

Probar con `~/Applications/Editorial OS.app` y `~/.editorial-os-mcp` ausentes.

Resultado esperado: ambos se crean correctamente.

## Reinstalación

Probar con Desktop y MCP existentes.

Resultado esperado: se crea backup previo y los instaladores actuales reemplazan/actualizan los componentes necesarios.

Verificar:

## Nota

La descarga desde una página web no puede ejecutar automáticamente un shell script por diseño de seguridad del navegador/macOS. El botón descarga el `.command`; el flujo por Terminal evita esa fricción y es el método recomendado.
