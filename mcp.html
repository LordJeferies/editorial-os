Controla Editorial OS con un asistente de IA.

El MCP trabaja contra el mismo Supabase y el mismo workspace de la app. Puede leer y modificar planner, contenidos, notas, producción, escenarios y marcas sin automatizar clics del navegador.

Descargar instalador MCPVer código

Cómo funciona

Asistente / host MCP │ │ stdio ▼ Editorial OS MCP local │ │ Supabase Auth + RLS ▼ public.editorial_state workspace: editorial-os │ ▼ Web / PWA / Desktop

El MCP modifica la misma fuente compartida. Si la app está conectada con el mismo usuario, recibe los cambios por Supabase.

Qué puede hacer

Planner

Leer la semana, añadir fichas, moverlas, quitarlas y vaciar el plan con protecciones.

Contenido

Crear y editar fichas reutilizables, buscar contenido y consultar la biblioteca.

Notas y producción

Añadir correcciones, cambiar estados, responsables, horarios y checklist.

Escenarios

Guardar el plan actual y aplicar escenarios existentes con confirmación.

Marcas

Listar, crear, editar y cambiar la marca activa.

Diagnóstico

Leer estado, revisión, historial, backup y criterios operativos.

Instalación

curl -fL "https://lordjeferies.github.io/editorial-os/INSTALL_EDITORIAL_MCP.command" -o "$HOME/Downloads/INSTALL_EDITORIAL_MCP.command" chmod +x "$HOME/Downloads/INSTALL_EDITORIAL_MCP.command" "$HOME/Downloads/INSTALL_EDITORIAL_MCP.command"

El instalador pide el email y la contraseña del usuario de Supabase. Si esa cuenta usa 4brxs, escribe 4brxs en ese momento. La contraseña queda sólo en ~/.editorial-os-mcp/.env.

Criterios de seguridad

  • Leer antes de escribir cuando el cambio dependa del estado actual.
  • Preservar campos desconocidos del payload.
  • No quitar fichas fixed salvo instrucción explícita.
  • Operaciones destructivas requieren confirmación.
  • Usar expectedRevision en secuencias críticas.
  • Mantener workspace_key = editorial-os.
  • No usar service_role para este flujo normal.
  • Se puede activar EDITORIAL_MCP_READ_ONLY=true.

Configuración genérica del host

{ "mcpServers": { "editorial-os": { "command": "/Users/TU_USUARIO/.editorial-os-mcp/run-mcp.sh", "args": [] } } }

La ubicación exacta donde pegar este bloque depende del host MCP que uses.
