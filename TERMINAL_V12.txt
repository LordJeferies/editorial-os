EDITORIAL OS V12 · ACTUALIZAR LA APP EXISTENTE

1) Descomprime EDITORIAL_OS_V12_PWA.zip en Downloads.

2) Abre Terminal y ejecuta:

cd ~/Downloads/EDITORIAL_OS_V12_PWA
chmod +x deploy_v12_over_existing.sh
./deploy_v12_over_existing.sh

El script intentará encontrar automáticamente tu repo actual.

Si no lo encuentra, usa la ruta explícita:

./deploy_v12_over_existing.sh ~/Downloads/EDITORIAL_OS_V10_FRESH

El script:
- hace un backup pre-V12;
- conserva .git;
- conserva el supabase-config.js que ya funciona;
- reemplaza el frontend por V12;
- valida JavaScript, bash, IDs, manifest, SW y contratos localStorage;
- hace commit;
- hace push a main;
- GitHub Pages publica la versión nueva.
