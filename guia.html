Editorial OS

Planifica, revisa y sincroniza contenido desde una sola app.

Editorial OS organiza una semana editorial, permite probar distintas combinaciones de contenido y mantiene el mismo estado entre web, PWA móvil y app Desktop.

Abrir Editorial OSVer repositorioInstalador Desktop

Qué hace

Planifica la semana

Construye el plan por día usando tablero, agenda o matriz. Las tres vistas editan el mismo plan.

Simula antes de publicar

Prueba frecuencia, mezcla de formatos y distribución por plataformas antes de convertirlo en una semana real.

Centraliza contenido

Guarda tipos de contenido, familias, pilares, plataformas, escenarios y estado de producción en un solo lugar.

Sincroniza dispositivos

Supabase permite mantener alineados Mac, iPhone, PWA y Desktop usando el mismo usuario.

Problemas que resuelve

ProblemaPlanificar en notas, chats y calendarios separados hace difícil ver la semana completa.
SoluciónUna sola fuente de verdad para la semana, escenarios, biblioteca y producción.
ProblemaArrastrar contenido en móvil puede ser impreciso y competir con el scroll.
SoluciónTres formas de construir lo mismo: Tablero, Agenda y Matriz, más acciones manuales.
ProblemaCambiar de vista o dispositivo puede generar versiones diferentes del plan.
SoluciónLas vistas comparten el mismo plannerDraft y Supabase sincroniza el estado.
ProblemaUna corrección se pierde si sólo vive en un chat externo.
SoluciónNotas por contenido con autor, fecha y contexto dentro de la propia ficha.

Planner: 3 maneras de armar la misma semana

1 · TableroEstilo Trello. Arrastra fichas entre días y reordénalas. Mejor para escritorio y para quien trabaja visualmente.
2 · AgendaDías uno debajo del otro. Selecciona contenido y usa “Añadir aquí”. Muy estable en móvil.
3 · MatrizContenido × días. Toca una celda para añadir. Es la manera más rápida de construir una semana completa sin drag.

Cambiar de Tablero a Agenda o Matriz no crea otro plan ni borra contenido. Son tres interfaces para la misma información.

Cómo configurar la app

1

Abre Configuración

En móvil toca ⚙. En desktop usa el botón “Configuración”.

2

Supabase ya viene configurado

Editorial OS ya incluye la Project URL y la clave pública de cliente. Normalmente no tienes que escribirlas.

3

Inicia sesión

Selecciona un perfil rápido o escribe manualmente email + contraseña. La sesión queda persistida en ese dispositivo.

4

Sincroniza

Una vez conectado puedes usar “Subir ahora” o “Bajar ahora”; después la app mantiene el estado compartido.

Cómo iniciar sesión

Modo rápido

En Configuración elige un perfil guardado. La app rellena el email. Tú sólo escribes la contraseña de ese usuario y pulsas Entrar.

Modo manual

Escribe email y contraseña directamente. Sirve para cualquier usuario autorizado de Supabase, aunque no esté guardado como perfil rápido.

Importante

La página pública no muestra contraseñas privadas. Los perfiles rápidos guardan el nombre/email localmente; la contraseña no se publica en GitHub.

Datos y sincronización

Supabase table: public.editorial_state workspace_key: editorial-os payload version: 9 Mismo usuario + mismo workspace = mismo estado editorial.

Editorial OS usa Auth de Supabase y una clave pública de cliente. Las claves privadas como service_role no deben estar dentro de una web pública.
